- [x] 1.2 Mecanismo del defecto **con evidencia medida** (sondeo `CustomTable` renderizado, `loadData` mockeado, contando `tr.ant-table-row`):
  - Con un **servidor fiel** (echo de `page`/`limit`, una página por request) y 34 registros: la tabla muestra **10/10/10/4** filas en las páginas 1–4 y el total «Total: 34 records (4 pages)». **El síntoma «10 → 12» NO se reproduce con páginas llenas** contra el backend real (`backend/src/http/ban.rs:189-218` hace `take(limit)` y devuelve `limit` tal cual) sobre **antd 6.6.6** (el repo usa `antd@^6.6.6`, no antd 5): antd 6 cortocircuita con `if (mergedData.length < total) { if (mergedData.length > pageSize) slice; return mergedData }` (`node_modules/antd/es/table/InternalTable.js:313-327`), y como `dataSource.length == pageSize` no recorta.
  - Variantes probadas: (a) última página incompleta → 4 filas, correcto; (b) recarga/repetidos de página → sin cambio; (c) **`limit` reportado por el servidor distinto del pedido** → **mecanismo real del «número que cambia»**: si la respuesta reporta `limit=12` para una petición `limit=10`, `fetchData` hace `pageSize: responseJson.pagination?.limit || 10` (`custom_table.tsx:380`) y el selector pasa a «12 / page» (con `dataSource` de 12 filas muestra 12); (d) **servidor que devuelve más filas que `pageSize`** → **recorte de antd** (`dataSource.length > pageSize` → `slice((current-1)*pageSize, current*pageSize)`): página 1 = 10 filas, página 2 = **2 filas** (antd avisa «`dataSource` length is less than `pagination.total` but large than `pagination.pageSize`»); (e) **`clientFilter`** → filtra **antes** del recorte (`custom_table.tsx:462-464`): con `pageSize=10` y un filtro que deja 6, muestra **6** filas.
  **Hecho:** tests `2.2` (antd re-slice: `expected 2 to be 10`) y `2.3` (pageSize reescrito: `expected '10 / page' to be '50 / page'`) fallan por el mecanismo documentado. El síntoma literal «10 → 12» con el backend actual **no ocurre**; lo que sí ocurre es (c) pageSize reescrito y (d) recorte de antd cuando `dataSource.length > pageSize`.
