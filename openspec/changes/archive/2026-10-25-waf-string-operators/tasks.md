- [x] 1.3 Semántica de `@streq`: casa con la igualdad exacta y no casa con una diferencia de un carácter ni con distinta capitalización. **Verificación:** el test falla.

- [x] 1.9 Evidencia: un operador de cadena con pipeline **no vacía** anota el valor **transformado** bajo la clave de la colección (y bajo la clave compuesta `colección[clave]` en las colecciones con clave); con pipeline **vacía** no anota nada; `@unconditionalMatch` sigue el mismo contrato. **Verificación:** los tests fallan.
